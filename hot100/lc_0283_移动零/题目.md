# LeetCode 283. 移动零

- 难度：简单
- 链接：https://leetcode.cn/problems/move-zeroes/
- 一句话：把数组里所有 0 移到末尾，非零元素保持原来的相对顺序；必须原地操作，不能复制数组。

## 输入格式（OJ 视角）

每组用例占两行：

1. 第一行 `n`：数组长度（`1 <= n <= 10^4`）
2. 第二行：`n` 个整数，空格分隔（`-2^31 <= nums[i] <= 2^31 - 1`）

多组用例依次排列，**读到文件结束（EOF）为止**。

```
5
0 1 0 3 12
```

## 输出格式

每组用例输出一行：移动 0 之后的数组，整数之间空格分隔（与 LeetCode 判题检查的原地修改结果一致）。

```
1 3 12 0 0
```

## 样例

输入：

```
5
0 1 0 3 12
```

输出：

```
1 3 12 0 0
```

## 边界用例（in.txt / out.txt 覆盖）

| 用例 | 输入 | 输出 |
| --- | --- | --- |
| 常规：题目样例 1 | `0 1 0 3 12` | `1 3 12 0 0` |
| 常规：题目样例 2（单元素为 0） | `0` | `0` |
| 边界：全 0 | `0 0 0` | `0 0 0` |
| 边界：无 0 | `1 2 3` | `1 2 3` |
| 边界：负数与多个 0 穿插 | `-1 0 2 0 0 5` | `-1 2 5 0 0 0` |
| 边界：单元素非 0 | `5` | `5` |
| 边界：0 在开头 | `0 1 2 3` | `1 2 3 0` |
| 边界：0 在中间多次出现 | `1 0 2 0 3` | `1 2 3 0 0` |
