# LeetCode 49. 字母异位词分组

- 难度：中等
- 链接：https://leetcode.cn/problems/group-anagrams/
- 一句话：把互为字母异位词的字符串分到同一组并返回所有分组。

## 输入格式（OJ 视角）

每组用例占两行：

1. 第一行 `n`：字符串个数（`1 <= n <= 10^4`）
2. 第二行：`n` 个字符串，空格分隔（每个串只含小写字母，长度 `0 <= k <= 100`）

多组用例依次排列，**读到文件结束（EOF）为止**。

```
6
eat tea tan ate nat bat
```

> 边界说明：词长可以为 0，即空串——`in.txt` 里没法直接写出"空 token"，需要覆盖这种情况时把该组的字符串换成题目给定的其他等价边界（如单字符 `a`）。

## 输出格式

每组用例输出若干行，**一个异位词分组占一行**，行内单词按字典序、空格分隔；行与行之间也按字典序排列。

> 为什么排序：分组本身是无序的，OJ 判题需要唯一确定的答案，所以在输出层做了规范化（算法返回的分组不排序）。

```
ate eat tea
bat
nat tan
```

## 样例

in.txt 第 1~2 行 / out.txt 第 1~3 行：

```
输入：n=6, strs=["eat","tea","tan","ate","nat","bat"]
输出：
ate eat tea
bat
nat tan
```

## 思路

异位词只是字母排列顺序不同，所以**把每个词内部排序后当作分组键**：`eat` / `tea` / `ate` 排序后都是 `aet`，天然落进同一组。扫一遍词表，用哈希表 `键 -> 该组的词列表` 归类即可。

判断两个词是否互为异位词，最笨的办法是比对全部排列（O(k!)）；"排序后比相等"只要 O(k log k)，再用哈希表把"找 s 属于哪一组"从两两比对降到 O(1)。

## 复杂度

- 时间 O(n·k·log k)：n 个词，每个词排序一次（k 为词长），哈希表查询摊还 O(1)。
- 空间 O(n·k)：哈希表存下所有词，也就是答案本身。

## 涉及知识点

- **哈希表（dict）**：键可以是字符串（不可变、可哈希）；列表不可哈希，不能直接当键。
- **`dict.setdefault(key, default)`**：键不存在就先写入默认值再返回，省掉两行 `if key not in d` 判断。
- **`sorted(iterable, key=None, reverse=False)`**：返回新列表，不原地修改。
- **`"".join(可迭代对象)`**：把字符列表拼回字符串当键。
- **`dict.values()`** 返回的是动态视图，`list()` 包一层才是 `List`。
- **`list.sort()` vs `sorted()`**：前者原地排序返回 `None`，后者返回新列表。
- **输出规范化**：分组无序 → 在输出层排序，保证判题答案唯一。

## 用例说明

| 组 | in.txt 行 | 输入                                | 覆盖点                                       |
| -- | --------- | ----------------------------------- | -------------------------------------------- |
| 1  | 1~2       | 6 个词，`eat/tea/tan/ate/nat/bat` | 题目样例：3 组，含单元素组                   |
| 2  | 3~4       | n=1,`["a"]`                       | 边界：最小规模、单字符词                     |
| 3  | 5~6       | 5 ×`"abc"`                       | 边界：全部相同（同一组里重复词都要保留）     |
| 4  | 7~8       | `ab/ba/ab/ba`                     | 边界：重复词 + 两两互为异位词                |
| 5  | 9~10      | `abc/cba/bca`                     | 常规：长度相同的三词全互为异位词             |
| 6  | 11~12     | `ab/abc/ba`                       | 边界：混入不同长度的词，考"不能只按长度分组" |
| 7  | 13~14     | `longword/gnolword`               | 常规：长词（k=8）互为异位词                  |

第 6 组是本题最容易错的地方：只按"词长"分组会把 `abc` 和 `ab` 混在一起；只按"字符和"分组会被 `ad` 与 `bc` 骗过。

## 其他解法（学习对比，不提交）

把"排序做键"换成"26 个字母计数做键"，单词 O(k log k) 压到 O(k)：

```python
class SolutionCountKey:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = {}
        for s in strs:
            cnt = [0] * 26                         # [0] * 26 生成 26 个 0（下标 0 是 'a'，25 是 'z'）
            for ch in s:
                cnt[ord(ch) - ord('a')] += 1       # ord(单字符) 取 Unicode 码点，ord('a') == 97
            key = tuple(cnt)                       # 列表可变、不可哈希 -> 转元组才能当字典键
            groups.setdefault(key, []).append(s)
        return list(groups.values())
```

总时间 O(n·k)（少一个 log 因子），但每次要建 26 长度的列表，常数更大；k 很小时两者差别不明显。**提交请用 `Solution` 那份。**

## 易错点

- **拿列表当字典键**：`groups[sorted(s)]` 会直接 `TypeError`，必须先 `"".join(...)` 或 `tuple(...)`。
- **忘了 `list()` 包 `values()`**：返回值是视图不是 `List`，提交回 LeetCode 类型校验不过。
- **只按长度分组**：`abc` 与 `ba` 长度不同还好，但 `abc` 与 `bcd` 长度相同却不同组 → 必须比字母构成。
- **输出顺序不稳定**：字典遍历顺序依赖插入顺序，若不排序，同一输入两次运行的行顺序可能不同，`diff` 会对不上。
- **漏掉重复词**：`["abc","abc"]` 应在同一组里出现两次，不能去重。
