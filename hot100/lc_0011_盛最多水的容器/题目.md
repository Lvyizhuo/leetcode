# LeetCode 11. 盛最多水的容器

- 难度：中等
- 链接：https://leetcode.cn/problems/container-with-most-water/
- 一句话：在柱状图里挑两根柱子，让它们与 x 轴围成的矩形面积（水量）最大，容器不能倾斜。

## 输入格式（OJ 视角）

每组用例占两行：第一行 n（柱子数量），第二行 n 个整数（每根柱子的高度，n 可为 0）。多组用例依次排列，读到文件结束。

## 输出格式

每组输出一行一个整数：能容纳的最大水量。

## 样例

in.txt 第一组：

```
9
1 8 6 2 5 4 8 3 7
```

out.txt 第一行：`49`（取下标 1 与 8：min(8, 7) × 7 = 49）

## 思路

双指针（对撞指针）从两端向中间收拢，每次只移动较矮那一侧的指针。

水量 = min(左柱高, 右柱高) × 宽度。若移动较高一侧，min(左, 右) 不可能变大（仍被较矮那根限制），宽度却变小，面积只可能更小；只有移动较矮一侧，才有机会遇到更高的柱子、抬高水量下限。两指针相遇前所有候选 (left, right) 组合都被检查过，因此不会漏掉最优解——这就是它比暴力枚举 O(n²) 快的原因。

## 复杂度

时间 O(n) / 空间 O(1)；n 为柱子数量。

## 涉及知识点

- 双指针（对撞指针）：left 从 0、right 从 n-1 相向而行
- 贪心收缩策略的正确性证明：为什么移高侧一定不优
- min / max 内置函数
- 多重赋值与 while 循环边界

## 用例说明

| 组 | in.txt 位置 | 覆盖点 |
| --- | --- | --- |
| 1 | 第 1~2 行 | 题目样例：答案 49 |
| 2 | 第 3~4 行 | 常规：答案在首尾（3 与 5 围出 12） |
| 3 | 第 5~6 行 | 常规：答案在中间（4 与 3 围出 4） |
| 4 | 第 7~8 行 | 边界：最小规模两根柱子（1 与 1 围出 1） |
| 5 | 第 9~10 行 | 边界：全部等高（4×3 = 12） |
| 6 | 第 11~12 行 | 边界：严格递增（最大 6） |
| 7 | 第 13~14 行 | 边界：单元素（无法形成容器，返回 0） |
| 8 | 第 15~16 行 | 边界：空数组（返回 0，while 不执行） |
| 9 | 第 17~18 行 | 边界：极值 10^9（1e9 × 1 = 1000000000） |

## 本地怎么跑

```bash
python lc_0011_盛最多水的容器.py < in.txt
diff <(python lc_0011_盛最多水的容器.py < in.txt) out.txt && echo PASS
```

## 易错点

- 高度取错：直接拿 height[left] × 宽会"溢出容器"，必须 min(左, 右) 才是实际水深。
- while 写成 `left <= right`：指针相遇后宽度为 0、高度取同一根，结果恒为 0，等于白算。
- 相等高度时移哪边都等价，但必须移动一侧，否则死循环。
- 单元素 / 空数组：while 不执行，best 保持 0，正好符合题意（少于两根柱子无法成容器）。
